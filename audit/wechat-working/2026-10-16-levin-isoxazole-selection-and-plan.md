## 中段叙事：按问题推进，不按图号报菜名

1. 从合成路线互补性切入：用Fig.3b的C4碘化/Suzuki以及C4锂化例子解释，为什么可先在异噁唑上安排取代基，再进入吡咯。与传统吡咯反应的比较仅限原文确实展示和讨论的连接方式。
2. 引入N-炔丙基烯胺酮这一共同中间体：异噁唑N-炔丙基化→还原开环→环化的一锅三阶段设计。不能写成一个基元步骤，不能把一锅法误写成全程同一溶剂不经处理。解释中间体兼容性及为何环化可能产生多条竞争路径。
3. 通过具有判别力的底物与分段实验检验机理：α-取代底物仍给目标吡咯，反驳旧的必须经α-allenyl去质子化的解释；炔丙基→丙二烯异构化与随后环化分开。丙二烯5a在溶液中得到表征，不能称作稳定纯品分离。中性噁氮杂七元环6能低效转化，不等于它是动力学合格中间体。
4. 由异常环化引出Fig.4：目标7-endo-dig通道与Conia-ene型通道竞争；结合A1,2/A1,3张力解释为何不同位置的位阻影响不同。保留作者的中性/阴离子工作模型与未排除路径，不把整套DFT路径写成直接观测。
5. 模型的价值与边界：Λ=%Vbur(C3)×%Vbur(C4)/%Vbur(C5)，用初始集合之外的11个例子检验，其中10个判断正确；主文定义目标优先为>5:1。SI Table S13的AUROC=0.968不是96.8%的普适准确率；1t为例外，仍需考虑电子效应。Parecoxib等C5-甲基例子具有机理简并性，产物形式等同不证明只走单原子编辑路径。
6. 合成实用性与限制一并写：主文报告10 mmol放大得到74%，但须保留该例40 h环化注释；氧化敏感吡咯的氮气柱层析要求、单取代底物低效、竞争烷基化官能团以及副产物不隐去。具体产率与时间以逐个原始实验为依据，不将不同实验的数字合并成统一标准。

## 审稿意见必须融入相应论证

### 创新性：三个有先例的过程，组合为何仍有价值？

Peer Review File pp.1、4–5。审稿人1承认工作价值，但明确指出N-烷基化、还原与烯胺酮成吡咯各有先例；同时肯定一锅兼容性和竞争路径的定量模型。作者回应着重于新的逆合成用途、区域专一中间体可及性、范围扩展以及对旧机理的修订。不可写成三个步骤均为首次发现。

### 对照的公平性：不能贬低全部传统吡咯合成

Peer Review File pp.2、7–9。审稿人2认为初稿对既有方法的描述过于笼统；作者重写引言，突出异噁唑与吡咯合成的正交/互补断键。此处与开篇价值判断及Fig.3b对应。

### 溶剂：改变介电常数，为什么仍解释不了实验？

Peer Review File pp.13–14；SI Table S5、S7。审稿人2问PCM(DMF)与实际NMP为何不一致。作者以NMP介电常数重算，能垒变化很小，承认隐式溶剂不足以描述特异相互作用；NMP氢键/一般碱活化是作者提出的解释。进一步检查DMA含水影响，表列DMA条件3%、DMA/H2O(10:1)58%。不能说DFT已证明氢键是全部收率差的唯一原因，也不能把两者描成已经全面排除其他变量的因果证明。

### 失败底物：不能把化学反应失败都归因于纯化

Peer Review File pp.5–6；SI p.S26/Scheme S3。三种单苯基异噁唑的补充实验显示目标产物极低或未检出，作者推测中间体稳定性不足而不只是产物氧化。明确实验结果与原因推测的区别。

Peer Review File pp.9–10。Cloxacillin、Rimisoxafen在更具亲核性的其他位点发生炔丙基化；Parecoxib例子49%不构成广泛复杂分子适用性的证明。最终审稿人2在Version 1（p.2）表示主要问题已解决，同时仍指出复杂底物适用性有限。不要沿用10月15日另一篇Nature的审稿结论。

### TEMPO：保留数据，不把猜测升级为已证实自由基机理

Peer Review File pp.14–16；SI Tables S8–S10、Scheme S1。作者报告TEMPO抑制二芳基底物还原阶段的副反应，并讨论可能的单电子过程；但在答复p.16明确表示对具体机理细节信心不足，未将该具体机理提案收入SI。正文可讨论这种证据自律，不能写“捕获实验已证实自由基链”。TEMPO增量虽可减少副产物，最终吡咯产率并非单调改善，须区分还原阶段与一锅终产率。

### 其他补充与证据上限

Peer Review File pp.16–17：异噻唑能形成烷基化产物，但N/S烷基化位点未被无歧义归属；还原后回到原料。不得写成已实现S→C编辑。谱图统一格式/补积分可以在制作审校时利用，不必硬塞进公众号核心叙事。
