## 本次用户可见回复（主体）

可以，而且建议把目前的「更换下载目录」升级成 **「选择 PDF 保存位置」**，让用户明确选择本机文件夹或云盘。

我核查了 Gallery 当前实现以及百度网盘的官方能力。技术上可以增加以下入口：

**PDF 保存位置 · 拟议界面**

| 类型 | 操作 | 说明 |
| --- | --- | --- |
| 本机文件夹 | 直接选择电脑目录 | 使用原有目录读取授权 |
| 百度网盘 | 登录并选择同步目录 | 从百度官方网站或客户端登录，启用可用的本地同步后选择电脑文件夹 |
| 夸克 / 阿里云盘 | 选择已同步的本地文件夹 | 只有本地实际可读取的文件才能被自动检索；不宣称已连通云端 API |
| OneDrive | 选择本地同步目录 | 可能存在在线占位文件，需确保可读取完整本地 PDF |

这是**拟议布局，尚未上线**。用户点击「百度网盘」后，Gallery 可以引导他前往百度官方页面或客户端登录，启用可用的本地同步功能，再返回 Gallery 选择对应的电脑文件夹。此后已同步到本机的 PDF 就能由现有 DOI 检索功能自动识别和打开。百度网盘和 OneDrive 都有客户端同步文件夹的机制，但具体功能取决于所用版本和账号权益。

需要区分两种方式：

- **本地同步目录型（建议先做）：** 在「更换下载目录」里出现品牌入口、官方安装/登录说明和「选择本机同步目录」操作。用户授权的是自己的电脑文件夹，不需要把百度密码交给 Gallery。完成绑定后沿用现有的 DOI 检查和原生阅读器；尚未同步到本机的云端文件不标为“可读”。无假登录按钮、无云盘已连接的误导性提示、无强制付费。
- **真正的云端目录直选型（独立二期）：** 如果希望在 Gallery 站内通过百度官方授权登录直接浏览网盘里的远程文件夹，无需先同步到电脑，就要对接百度网盘开放平台 OAuth 和文件管理/上传下载 API，办理必要的应用授权与权限申请，可能还有服务政策限制。普通网页的 showDirectoryPicker 只能选择浏览器/操作系统暴露的目录，无法仅凭网页登录枚举百度网盘云端目录。目前不能宣称该接口已经接入或用户已登录。

UI 引导应是用户自愿选择：点击「百度网盘」→「到百度官方登录/安装客户端」→「确认文件已同步到电脑」→「选择同步目录并授予读取权限」。登录窗口只在百度官方域名或其官方客户端进行，Gallery 不采集百度网盘账号密码，不读取超出用户选择范围的磁盘文件。浏览器文件夹选择器必须由用户主动点击触发，不能从外部网站登录跳转后自动静默打开。

**我的建议是先做无需额外网盘 API 的第一阶段。** 这就能呈现百度网盘、OneDrive 等选项并保留当前的本地 PDF 自动匹配流程，而不会在用户尚未同步文件时假装能读云端 PDF。

按本项目既定的“先核实、用户批准后修复/实施”规则，我目前仅做了只读核查，**没有修改或发布这些云盘选项**。是否批准按该第一阶段修改「更换下载目录」？如果你需要“在 Gallery 内直接登录百度网盘、浏览真正的云端文件夹”，则应另行确定 OAuth 对接范围。

## 安全/产品注意点

- 品牌入口与开发者已经对接真实云盘 OAuth 是不同产品状态，文案必须区分。
- 用户登录第三方服务只在官方站点/客户端；Gallery 不要求账号密码。
- OneDrive 等按需同步的“仅在线”文件，若无法取得真实字节，不得展示为已下载。
- 原来账号/设备隔离、PDF SHA-256 与 DOI 验证、文件夹只读授权、每日北京时间 08:00 文献发布契约不变。
- 目前没有改动用户原文件、IndexedDB/R2/D1，未提交功能 PR。
