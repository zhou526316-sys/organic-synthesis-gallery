# 腾讯云服务器 SSH 登录：Windows PowerShell

北京时间：2026-10-08T19:36:32.572+08:00
上下文：用户要求补充登录现有腾讯云 Ubuntu 22.04 服务器的实际 PowerShell 命令，配合之前只读的零新增费用 PDF 网关检查。

## 完整用户可见回复

在 **Windows PowerShell** 中，先运行：

```powershell
ssh -p 22 ubuntu@43.135.32.73
```

这是用 SSH 登录此前截图中的腾讯云 Ubuntu 服务器。用户名若不是 `ubuntu`，而是你原来使用的 `root`，则运行：

```powershell
ssh -p 22 root@43.135.32.73
```

只执行与你的服务器实际登录用户名对应的一条命令，不必两条都执行。

首次连接如出现主机指纹确认，请先在腾讯云控制台核对指纹，再输入 `yes`；随后按提示使用原来设置的登录密码或 SSH 密钥。**输入密码时终端不显示字符，属于正常情况。**

如果服务器使用本地私钥登录，命令是：

```powershell
ssh -i "C:\你的私钥文件路径\你的密钥.pem" -p 22 ubuntu@43.135.32.73
```

把中文路径替换为你电脑上实际的密钥文件路径，不要把密码或私钥发送到聊天中。

登录成功后，命令提示符一般会变为 `ubuntu@服务器名:~$` 或 `root@服务器名:~#`。你可以先用下面三个**只读**命令确认服务器状态：

```bash
whoami
free -h
ss -ltn '( sport = :80 or sport = :443 )'
```

之后即可运行我上条消息中提供的服务器检查代码。检查完输入 `exit` 退出 SSH。若提示 `Connection timed out` 或 `Permission denied`，把**错误文字（不含密钥）**发给我；SSH 22 端口可能未开放，届时应改用腾讯云控制台的“登录”网页终端，不需要改动 Clash。

**这些登录和检查命令不会购买服务，也不会改动服务器或微信公众号中继。**
