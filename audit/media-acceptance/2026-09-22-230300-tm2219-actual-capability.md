There were 18 figure_stage starts and 18 completion events; deduplicated current staged inventory has 16 assets. Upload events and distinct stored assets are different measures.
The old browser flow requests /api/article-figures/import before staging. The production route was deliberately locked during recovery; this was a recovery integration defect, not a reason for the user to wait longer or reset credentials.
An additional old-flow defect: combined GM/fetch transport failures do not carry a >=500 HTTP status; uploadArticleFigure stops on status <500 and never reaches staging for those failures. Direct staging removes that unnecessary preceding failure point but does not guarantee that an unrelated network failure to the staging endpoint is solved.
Several per-paper publisher successes coexist with later controller_timeout reports, including JOC 6c01270, Nature Chemistry s41557-026-02258-8, Nature Synthesis s44160-026-01155-9, OL 6c03279 and OL 6c03418. This is evidence of unreliable capture-result acknowledgement, not evidence that the corresponding object bytes are absent. The precise stale-tab/storage cause remains subject to bound-job regression.

## Main-text SVG and resolution findings

All seven new staged SVG objects contain SVG structure and vector paths; some also contain embedded raster elements, so not all are pure-vector images.
Current main's media-write.js parseImageData accepts png/jpeg/gif/webp, not image/svg+xml. Its promotion path passes the staged SVG's MIME type through to importFigure. Thus SVG staging and formal-import format support are inconsistent; it is not enough to say staged=true.
The following Nature Figure 1 pairs exist in the retrieved files:
- 10.1038/s41557-026-02258-8: local fallback image-095 is PNG 1200x793; staged image-105 is WebP 685x453.
- 10.1038/s44160-026-01155-9: local fallback image-097 is PNG 1200x1498; staged image-108 is WebP 685x855.
The same article's capture pipeline therefore selected a smaller actual asset for the article-figure role even though a larger Figure 1 had already been captured. This is stronger evidence than merely guessing a higher-resolution URL, but is not a claim that every other figure has an accessible high-resolution variant.
Low-resolution trace failures include SVG candidates from OL articles. Display dimensions alone must not be treated as equivalent to raster resolution. Do not solve this by indiscriminately lowering all raster thresholds; parse and verify the actual vector/raster content and preserve accurate quality labels.
