## Published acquisition behavior

One DOI is handled in one full-text visit for TOC plus numbered Figure/Scheme/Chart images, sequentially rather than concurrent article tabs. Missing TOC does not prevent body-image attempts. Existing official TOCs are preserved.
High-resolution candidate URLs no longer silently fall back to thumbnail currentSrc; actual candidate dimensions and safe vector structure are compared. SVG and raster quality handling are distinct. Old-tab/task nonce, article-page DOI and candidate source DOI guards are retained at client and server boundaries.
Per-visit new semantic-figure budget is 20, subject to the article time budget. Per-image verified storage receipts are checkpointed so partial capture can resume without discarding successful work. Completion generation is stable across queue-generatedAt changes.
Default batch size is 8 with a 12-second delay before another runnable batch. Article failures/timeouts do not intentionally stop the entire queue; bounded retries/backoff and checkpoint reuse prevent rapid repeated attempts. Network/startup exceptions schedule a later retry. No claim that any queue can finish within one night.
The same installed script identity and token keys are preserved. User should update in place, not uninstall or clear Tampermonkey storage; stop/close old task tabs, keep one freshly reloaded Gallery controller page, then use the existing menu command '继续媒体抓取主线' to clear their previous pause state.
An unattended session requires the user's browser and VPN to remain connected and the computer not to sleep. Authentication/session expiry or publisher CAPTCHA may still require human handling. Actual authenticated publisher sessions have not been end-to-end verified by this release's fixture tests.
