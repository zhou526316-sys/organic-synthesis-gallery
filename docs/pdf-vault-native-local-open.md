# 本地 PDF：按文献卡片 DOI 直接打开（浏览器原生阅读器）

## 用户操作

每篇正式文献的“本地 PDF”链接直达 `/pdf-vault/open/?doi=...`，在浏览器新标签页打开，而非先进入文献库管理页。该页面联网验证当前 Gallery 账号、读取该设备上对应 DOI 的持久化文件记录，并用浏览器自己的 PDF 阅读功能显示原文件。

- 已关联且仍有权限：直接在新标签中展示 PDF，使用浏览器内置缩放、打印、下载及连续滚动功能。
- 电脑上有文件但尚未关联：首次点击“选择电脑上已有的 PDF”，在 Chrome/Edge 文件选择器里从任意位置选择（下载目录、桌面、D 盘、已本地同步的云盘目录等）。用户必须自己确认文件和 DOI 对应。关联后下次点击卡片不再要求重复选择。
- 未下载：通过 DOI 官方解析地址跳转到期刊文章页面自行下载，之后返回关联 PDF。期刊或学校访问权限仍由期刊侧管理。
- 文件移动、修改或浏览器权限失效：停止自动打开，显示原因，提供重新选择文件与恢复读取权限。
- 不支持 `showOpenFilePicker` 的浏览器：原有 `/pdf-vault/?doi=...` 仍可用于导入到选择的真实目录/OPFS。普通网页不能承诺自动关联任意磁盘路径。

## 浏览器与隐私边界

普通网页无权在未经用户授权时扫描所有硬盘文件、拦截浏览器下载、读取任意 `file://` 路径，也不能把文件系统全局索引到同一个账号。首次选取任何位置的原文件必须由用户授权。浏览器是否在重启后保持授权由用户设备与浏览器决定。

`FileSystemFileHandle` 使用 IndexedDB 的结构化克隆机制保存在当前站点来源的当前浏览器，关联记录按已验证用户 ID 与设备 ID 隔离；文件字节、原始路径、文件名及哈希均不上传。内容读取在本机检查 PDF 格式、大小和 SHA-256，重新打开时复核。退出账号或切换账号时关闭内置查看框架并释放 blob URL。已同步到本地的云盘文件可像普通文件一样关联；未同步的网盘云端文件需要另行授权云存储集成，网页不能直接读取。

直接阅读由浏览器内置 PDF 查看器处理，嵌入在占满浏览器新标签的 iframe 中。若用户关闭浏览器内置 PDF 阅读功能，应依照浏览器设置恢复；这是浏览器自身的行为而不是 Gallery 服务器的 PDF.js 翻页逻辑。

## 验收

- 验证文献卡片链接只有 DOI，不含 token、路径、PDF、哈希。
- 用真实 IndexedDB、OPFS 和持久 FileSystemFileHandle 验证选取、关联、重新打开、文件不复制、不重命名及退出账号后关闭。
- 验证已导入文献库的旧副本仍可直接打开，新旧路径兼容。
- Chrome/Edge 原生文件选择器权限属于用户设备原生弹窗，CI 只可模拟用户动作，不把模拟当作用户设备实测。

上线仍必须经过 PDF Vault P1 与站点正式 Pages 发布门禁，不更改每日 08:00 文献发布规则。

## 2026-10-11 批准的体验修订：下载目录自动发现与 DOI 安全关联

### 登录与打开

- 主站完成服务器会话验证后，使用仅在当前浏览器保存的短期会话核验记录（哈希绑定令牌及用户），新文献标签可以直接查找本地文件，不重复阻塞等候登录接口。后台仍复核服务器会话；明确失效、退出或切换账号时关闭已打开文件。仅凭令牌存在、历史用户名或过期记录**不能**授权读取；服务端可能在不同设备操作后撤销会话，短时缓存不是永久读权限。
- 文件访问权限与账号登录权限独立：如果 Edge/Chrome 撤回文件夹权限，仍须由用户点击恢复；网页无法代替操作系统授权。

### 首次授权一次下载目录

1. 在 Edge/Chrome 任意有 DOI 的 Gallery 文献卡片点击「本地 PDF」。
2. 无关联时点击「授权 PDF 下载目录（只读）」，选择浏览器实际下载 PDF 的目录。仅请求读取权限，不创建、修改或上传下载目录中的文件。若浏览器出于安全策略不允许选择系统下载根目录，可在浏览器下载设置中使用一个自己选择的 PDF 子目录，并授权该目录。
3. 以后下载新的正文 PDF 到此目录，点击相应卡片即在本机对该目录及一级子目录进行有界、增量的 DOI 索引与匹配。目录中近期新增文件优先核对，旧文件结果按大小、修改时间缓存；每次操作有数量和时间上限，可点击「重新搜索已下载 PDF」继续索引。
4. 匹配成功时，原始 PDF 仍在原位置，浏览器新标签显示内置连续滚动阅读器；不会让用户为每篇已下载文件再打开一次选取窗口。直接链接也只包含 DOI，不包含本地路径、账户令牌或 PDF 字节。

### 纠错与安全

- **内容校验而非文件名猜测：** 导入前先解析 PDF，获取出版社元数据与第一页正文 DOI；只有唯一可确认的 DOI 与当前卡片一致才允许自动关联。具有其他 DOI、歧义、无法识别正文 DOI 或被判为 SI 的文件均不得自动打开成论文正文。纯图片扫描等不可识别 DOI 的 PDF 提示更换来源，不静默猜测。
- **历史关联：** 旧版已关联的 PDF 也在显示前核对内容 DOI。确认不符时，标记该条本机关联为不可用，尝试继续查找正确的 PDF。
- **更换／取消关联：** 阅读器右下角的「管理此 PDF」可随时更换、解除本 DOI 的本地关联或重新搜索目录；原始文件不会删除、覆盖或上传。重新绑定正确 PDF 时，旧的同 DOI 本机副本索引停用，防止回退到错误内容。
- **权限与边界：** 用户仅授权一个目录时，普通网页无法监听或扫描其他磁盘目录，不承诺「所有任意位置下载即自动匹配」。文件访问句柄保留在当前设备和浏览器的 IndexedDB；目录索引为本地缓存，不同步到其他设备。仍保留每篇 50 MiB 的本地校验限制。
- **验收：** Node DOI 规则测试、真实 Chromium IndexedDB/OPFS/文件句柄测试，旧版账号隔离及私有 PDF 回归、站点构建和正式 Pages 媒体资源交付核验都必须通过。模拟目录选择不代表用户 Windows 真实系统授权已经验证。

此更新不改变 08:00 文献发布、私人 PDF 权限、R2 或采集脚本。
